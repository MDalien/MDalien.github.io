Building a Cowrie SSH Honeypot

I've been working on my cybersecurity homelab, and one of the projects I'm building is an SSH honeypot using Cowrie. I wanted to do more than just install a tool and call it a project. I want to understand what happens when someone connects to a service, what gets logged, and how I can use that information to investigate activity.

My setup

Here's what I'm using for the lab:

  • Windows PC
  • Oracle VirtualBox
  • Ubuntu Linux VM
  • Cowrie SSH honeypot
  • TCP port 2222 for testing

I'm keeping everything in a virtual lab so I can test things in a controlled environment without exposing the honeypot to the public internet.

Getting Cowrie running

I installed the prerequisites, cloned the official Cowrie repository, set up a Python virtual environment, and installed the dependencies. After configuring and starting Cowrie, I checked that the service was running.

Cowrie is different from a normal SSH server. It gives you an emulated Linux environment, so the commands you enter interact with the honeypot's fake environment rather than giving you a real root shell on the host.

I then connected over SSH using the local loopback address on port 2222 and tried a few harmless commands. That was my first test to make sure I could connect and that Cowrie was recording the session.

Checking the logs

One of the main reasons I chose Cowrie is the logs. It can record authentication activity, commands entered during a session, and other connection details in a JSON event log.

The file I'm looking at is var/log/cowrie/cowrie.json. Since the events are structured, I can use Python later to break them down and look for patterns instead of reading through everything manually.

This is the part I want to spend more time on. Understanding what the events mean and figuring out what deserves attention is where the security side gets interesting.

What's next?

I'm going to dig deeper into the logs and build a small Python script to summarize the activity, such as attempted usernames, source addresses, and commands. After that, I want to connect Cowrie to Wazuh so I can work on centralized monitoring, alerts, and investigating suspicious activity.

I'm still building this out, but the goal is to actually demonstrate what I've learned.
